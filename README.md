🍏 Food Waste Reduction System

📌 Overview

The Food Waste Reduction System is a web application developed using HTML, CSS, and JavaScript. It helps reduce food waste by managing food inventory, tracking expiry dates, and connecting food donors with receivers through phone numbers for easy coordination.

✨ Features

- Add and manage food items
- Track expiry dates
- Alerts for expiring food
- AI-based recommendations
- Donate surplus food
- Donor and receiver phone tracking
- Inventory dashboard and waste statistics

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open index.html in any web browser.
